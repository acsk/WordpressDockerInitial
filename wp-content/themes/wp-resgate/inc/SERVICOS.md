# Como Gerenciar os Serviços

## 📋 Visão Geral

O Custom Post Type **"Serviços"** permite gerenciar facilmente os serviços que aparecem na seção "O que fazemos" do seu site, diretamente pelo painel do WordPress.

## 🚀 Como Acessar

1. Entre no **painel do WordPress** (wp-admin)
2. Vá em **Aparência > Serviços**
3. Você verá uma lista dos serviços já cadastrados

## ➕ Adicionar Novo Serviço

### Passo 1: Criar o Serviço
1. Clique em **"Adicionar Novo"**
2. Preencha o **título** do serviço (ex: "Remoção de malware")
3. **Escreva a descrição completa** no editor principal
   - Detalhe o que está incluído no serviço
   - Use listas com • para organizar benefícios
   - Mencione garantias e diferenciais
   - Seja específico sobre resultados

### Passo 2: Detalhes do Serviço
Na seção **"Detalhes do Serviço"**:

- **Ícone do Serviço** *(obrigatório)*: Classe Bootstrap Icons
  - Exemplos: `bi-bug`, `bi-tools`, `bi-speedometer2`
  - [Ver ícones disponíveis](https://icons.getbootstrap.com/)
- **Cor do Ícone**: Escolha entre 6 cores disponíveis
  - Azul (padrão), Verde, Laranja, Vermelho, Ciano, Cinza
- **Preço "A partir de"**: Preço inicial (ex: "R$ 150", "Consulte")
- **Serviço em Destaque**: Marque para destacar serviços principais
- **Texto da Badge**: Texto personalizado para a badge (ex: "Popular", "Urgente", "Novo")
- **Descrição Resumida**: Texto curto para o card (máximo 2 linhas)

### Passo 3: Ordenação
- Use o campo **"Ordem"** (lateral direita) para definir a sequência
- Números menores aparecem primeiro

### Passo 4: Publicar
1. Clique em **"Publicar"**
2. O serviço aparecerá automaticamente no site

## ✏️ Editar Serviços Existentes

1. Na listagem, clique no **título do serviço** que deseja editar
2. Faça as alterações necessárias
3. Clique em **"Atualizar"**

## 📊 Visualização na Listagem

A listagem mostra:
- **Título** do serviço
- **Ícone** (visual com cor aplicada)
- **Cor** (nome da cor selecionada)
- **Descrição** (resumo do conteúdo)
- **Preço** (se definido)
- **Destaque** (se marcado como destaque)
- **Ordem** (número da ordenação)
- **Data** de criação

## ⭐ Sistema de Destaques

### Como Funciona
- Serviços marcados como **"Destaque"** recebem:
  - Badge personalizada no canto superior direito
  - Background gradiente sutil
  - Borda colorida diferenciada
  - Barra gradiente no topo do card
  - Maior destaque visual

### Textos de Badge Personalizados
- **Popular** - Para serviços mais procurados
- **Urgente** - Para serviços de emergência (malware, hacks)
- **Novo** - Para serviços recém-lançados
- **Recomendado** - Para serviços que você quer destacar
- **Promoção** - Para serviços em oferta
- **Premium** - Para serviços de alto valor

### Estratégia Recomendada
- Marque **1-2 serviços principais** como destaque
- Escolha os serviços **mais procurados** ou **lucrativos**
- **Alterne ocasionalmente** para testar diferentes serviços

## 🎨 Cores e Ícones

### Cores Disponíveis
- **Azul (Primary)**: Serviços técnicos gerais
- **Verde (Success)**: Performance, otimização, sucesso
- **Laranja (Warning)**: Correções, alertas, manutenção
- **Vermelho (Danger)**: Segurança, remoção de malware
- **Ciano (Info)**: Informações, migrações, consultorias
- **Cinza (Secondary)**: Serviços complementares

### Ícones Recomendados por Categoria

#### Segurança
- `bi-shield-check` - Proteção geral
- `bi-bug` - Remoção de malware
- `bi-lock` - Segurança avançada

#### Técnico/Correções
- `bi-tools` - Correção de bugs
- `bi-wrench-adjustable` - Manutenção
- `bi-gear` - Configurações

#### Performance
- `bi-speedometer2` - Otimização de velocidade
- `bi-lightning` - Performance
- `bi-rocket` - Aceleração

#### Migração/Transferência
- `bi-arrow-left-right` - Migração
- `bi-box-arrow-up` - Upload/Deploy
- `bi-cloud-upload` - Cloud migration

#### Backup/Restauração
- `bi-cloud-download` - Backup
- `bi-arrow-clockwise` - Restauração
- `bi-database` - Banco de dados

## 🔄 Ordenação dos Serviços

### Como Ordenar
1. **Edite cada serviço** individualmente
2. Na lateral direita, encontre **"Atributos da página"**
3. Defina a **"Ordem"** (números menores aparecem primeiro)
4. **Salve** as alterações

### Estratégia de Ordenação
1. **Serviços em destaque** primeiro (ordem 1, 2)
2. **Serviços principais** na sequência (ordem 3, 4)
3. **Serviços complementares** por último (ordem 5+)

## 💰 Configuração de Preços

### Formatos Recomendados
- `A partir de R$ 150` - Preço mínimo
- `R$ 300 - R$ 500` - Faixa de preço
- `Consulte` - Serviços sob medida
- `Gratuito` - Serviços gratuitos
- Deixar vazio - Sem exibição de preço

### Estratégias de Precificação
- **Transparência**: Mostre preços quando possível
- **Competitividade**: Use "A partir de" para flexibilidade
- **Consulta**: Para serviços complexos ou personalizados

## 📱 Como Aparece no Site

### Estrutura Visual
- **Layout em grid**: 4 colunas no desktop, responsivo
- **Cards elegantes** com hover effects
- **Ícone circular** com cor personalizada no topo
- **Título** em destaque
- **Descrição** resumida
- **Preço** (se definido) na parte inferior
- **Badge "Popular"** para serviços em destaque

### Animações
- **Hover suave** com elevação do card
- **Ícone animado** com rotação e escala
- **Efeitos de borda** para serviços destacados

## 🎯 Melhores Práticas

### Títulos Eficazes
- **Claros e diretos**: "Remoção de malware"
- **Orientados a benefício**: "Otimização de performance"
- **Evite jargões**: Use linguagem que o cliente entende

### Descrições Resumidas
- **Máximo 2 linhas** no card
- **Foque no benefício principal**
- **Use linguagem persuasiva**
- **Seja específico**: "Até 300% mais rápido"

### Descrições Completas (Editor)
- **Liste o que está incluído**
- **Use bullet points** para facilitar leitura
- **Mencione garantias** e diferenciais
- **Inclua resultados esperados**
- **Adicione informações técnicas** relevantes

### Exemplo de Descrição Completa
```
Serviço especializado em limpeza completa de sites WordPress infectados:

• Análise detalhada de todos os arquivos
• Remoção completa de códigos maliciosos
• Restauração de arquivos corrompidos
• Hardening de segurança pós-limpeza
• Monitoramento por 30 dias
• Blacklist removal (Google, McAfee, etc.)

Garantimos que seu site ficará 100% limpo e protegido.
```

## 🔧 Para Desenvolvedores

### Função Helper
```php
$services = wp_resgate_get_services();
```

### Estrutura dos Dados
```php
[
    'title' => 'Nome do Serviço',
    'description' => 'Descrição resumida',
    'content' => 'Conteúdo completo',
    'icon' => 'bi-bug',
    'color' => 'danger',
    'price' => 'A partir de R$ 250',
    'featured' => true,
    'badge_text' => 'Popular'
]
```

### Meta Fields Disponíveis
- `_service_icon`: Classe do ícone Bootstrap
- `_service_color`: Cor do ícone (primary, success, etc.)
- `_service_price_from`: Preço inicial
- `_service_featured`: Serviço em destaque (1 ou vazio)
- `_service_badge_text`: Texto personalizado da badge

### Ordenação
- Por `menu_order` (campo "Ordem" no admin)
- Serviços em destaque têm prioridade visual

## 🆘 Solução de Problemas

### Serviços não aparecem no site
1. Verifique se estão **publicados** (não em rascunho)
2. Confirme se o **ícone** está preenchido
3. Limpe o cache do site se usar plugin de cache

### Ícones não aparecem
1. Verifique se a **classe do ícone** está correta
2. Use o formato `bi-nome-do-icone`
3. Consulte a [documentação oficial](https://icons.getbootstrap.com/)

### Ordem incorreta dos serviços
1. Edite cada serviço individualmente
2. Ajuste o campo **"Ordem"** na lateral direita
3. Números menores aparecem primeiro
4. Salve as alterações

### Cores não aplicadas
1. Verifique se uma **cor foi selecionada**
2. Salve o serviço novamente
3. Limpe o cache se necessário

## 💡 Dicas de Conversão

### Otimização para Vendas
- **Destaque benefícios**, não apenas recursos
- **Use números específicos**: "300% mais rápido"
- **Inclua garantias**: "100% limpo", "Zero downtime"
- **Mencione urgência**: "Resolução em 24h"

### Estrutura Persuasiva
1. **Problema** que o serviço resolve
2. **Solução** oferecida
3. **Benefícios** específicos
4. **Garantias** ou diferenciais
5. **Call to action** implícito

### A/B Testing
- **Teste diferentes ícones** para o mesmo serviço
- **Varie as cores** para ver impacto
- **Experimente preços** diferentes
- **Alterne serviços em destaque**

### Seasonal Updates
- **Atualize preços** conforme necessário
- **Adicione novos serviços** baseados na demanda
- **Destaque serviços sazonais** (Black Friday, fim de ano)
- **Remova serviços** que não convertem
